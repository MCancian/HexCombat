The Mission

HexCombat is an LLM-built version of the manual boardgame developed for CSIS / MIT research.

  • Primary: AI-vs-AI Research Instrument
    Enables headless batch games, generating Monte Carlo outcome distributions. It features an LLM JSON API allowing AI players to direct the simulation autonomously.
  • Secondary: Live-Adjudication Aid
    A facilitator can enter orders for both sides in the UI, letting the simulation resolve complex combat mathematics in real-time. Designed with a projector-friendly display.

Capacity & Throughput

Day 1 assault maneuver BNs bypass throughput gates. Day 2+ forces compete for daily beach tonnage (2200t / BN). Capacity scales with floating piers and Jack-up barges, but is hard-capped by port availability (Auto-JLSF).

One Game's Results

Full ROC Defense — Northern Beachhead, seed 20260710. Red (PLA) and Green (ROC), both driven by an LLM through the JSON API — 30 turns, start to finish.

  • Turn 1 — the assault crosses. 148 hulls sail at four beaches; ROC anti-ship fire and mines sink 29, damage 21, drown 10 battalions at sea.

  • Turn 30 — no decisive winner. Final census Red 4 : Green 59 battalions ashore: the landing is contained, not thrown back.

Not One Game — Thousands

One game is an anecdote. Because every game is deterministic under a seed — hierarchical, per-phase RNG, so the same seed reproduces the game exactly — HexCombat runs the same matchup across hundreds of seeds headlessly (without the LLMs, using scripted deterministic play) and reads the distribution of outcomes.

Parameter sweeps turn a single knob — beach capacity, mine density, CRBM maneuver — and measure how the outcome curve shifts. This is the primary mission: an instrument, not a match.

Where the Invasion Culminates

The 100% PLA win rate isn't doctrine — it's that the default offload throughput is set generously. The amphibious wave self-delivers on turn 1 and captures the Taipei port for free (it sits on the assault-beach hex); the non-amphibious follow-on then competes for beach/port throughput.

So the invasion is logistics-limited — it just never binds at 4,400 t/day. Throttle the beach offload rate and the follow-on plateaus below the ROC count: the campaign culminates. The tipping point is sharp.

Logistics Is the Biggest Knob We Have

Analysts reach for what’s visible — missiles fired, ships sunk, the opening salvo. The variable that actually decides this fight is the least glamorous one: how fast the follow-on can be unloaded. Throughput, not firepower.

500 → 14: Why It Takes a Human and an AI

  • Absurd Intuition: An early run said the ROC would need ~500 off-island Harpoon strikes per turn to make the invasion inviable. That number is absurd on its face.
  • Bug Hunt: That intuition triggered the hunt. The AI developer traced it to a correctness bug: battalions that drowned in the strait crossing were still counted as ashore.
  • The Real Threshold: Fixed, the knife-edge is ~14 strikes/turn.
  • Expert Judgment + AI: The expert knows 500 is wrong; the AI reads the census code, isolates the ghost, and re-runs thousands of games to prove the fix.

Honest Limits, Clear Roadmap

Limits

  • LLM play quality is bounded by the model — commanders reason locally, not campaign-deep.
  • LLM play requires extensive compute time.
  • Live human-facilitator play is still landing (order entry, front-line draw).

Where it's going

  • Model Changes: Ship magazines, ability for Red to switch beaches, etc.
  • Feature Changes: Live Godot map, order-entry facilitator flow, front-line polyline-draw UI.
  • Research Changes: Monte Carlo dashboards, LLM prompt variants, etc.
